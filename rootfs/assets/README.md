# Debian desktop icon

`debian-openlogo.svg` is the Debian Open Use Logo without text, from
https://www.debian.org/logos/openlogo-nd.svg (https://www.debian.org/logos/).
Copyright (c) 1999 Software in the Public Interest, Inc.; created by Raul Silva.
Licensed under LGPL-3.0-or-later or CC-BY-SA-3.0.

`anland-debian-128.png` and `anland-debian-256.png` render that SVG centered on a
transparent square with padding for Android task icons. The desktop entry uses
`anland-debian` so the task and launcher resolve the same packaged icon.
